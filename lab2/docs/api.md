# API (Node-RED, лабораторная работа №2)

Автор: Коростелкина Диана Алексеевна, группа СДП-УИР-241.

Базовый адрес: `http://localhost:1880`. Все эндпоинты принимают только метод **GET**.
Реализация: flow `08 Endpoints Korostelkina SDP-UIR-241` (`lab2/flows/flow-08-endpoints.json`).
Каждый эндпоинт состоит из ноды `http in` и ноды `http response`.

## 1. GET /api/text

Возвращает простой текст.

- Параметры: нет.
- Заголовок ответа: `Content-Type: text/plain; charset=utf-8`.

Пример запроса:

```
curl.exe http://localhost:1880/api/text
```

Ответ `200 OK`:

```
Привет! Это API студентки Коростелкиной Д.А., группа СДП-УИР-241.
```

## 2. GET /api/info

Возвращает JSON с двумя полями.

- Параметры: нет.
- Заголовок ответа: `Content-Type: application/json`.

Пример запроса:

```
curl.exe http://localhost:1880/api/info
```

Ответ `200 OK`:

```json
{
  "student": "Коростелкина Диана Алексеевна",
  "group": "СДП-УИР-241"
}
```

## 3. GET /api/items

Работает с набором из четырёх элементов (поля `id`, `name`, `price`):

| id | name | price |
|----|------|-------|
| 1 | Ноутбук | 1500 |
| 2 | Мышь | 50 |
| 3 | Клавиатура | 120 |
| 4 | Монитор | 600 |

### 3.1. GET /api/items/:id (path-параметр)

| Параметр | Где | Тип | Описание |
|----------|-----|-----|----------|
| `id` | путь | целое число >= 1 | идентификатор элемента |

Успешный запрос:

```
curl.exe http://localhost:1880/api/items/2
```

Ответ `200 OK`:

```json
{ "id": 2, "name": "Мышь", "price": 50 }
```

Ошибка `400 Bad Request` (id не число):

```
curl.exe -i http://localhost:1880/api/items/abc
```

```json
{ "error": "Bad Request", "message": "id должен быть положительным целым числом" }
```

Ошибка `404 Not Found` (элемента с таким id нет):

```
curl.exe -i http://localhost:1880/api/items/99
```

```json
{ "error": "Not Found", "message": "Элемент с id 99 не найден" }
```

### 3.2. GET /api/items?limit=N (query-параметр)

| Параметр | Где | Тип | Обязательный | Описание |
|----------|-----|-----|--------------|----------|
| `limit` | query | целое число >= 1 | нет | сколько элементов вернуть (по умолчанию все) |

Успешный запрос:

```
curl.exe "http://localhost:1880/api/items?limit=2"
```

Ответ `200 OK`:

```json
[
  { "id": 1, "name": "Ноутбук", "price": 1500 },
  { "id": 2, "name": "Мышь", "price": 50 }
]
```

Без параметра (`/api/items`) вернётся весь список из четырёх элементов.

Ошибка `400 Bad Request`:

```
curl.exe -i "http://localhost:1880/api/items?limit=0"
```

```json
{ "error": "Bad Request", "message": "limit должен быть положительным целым числом" }
```

## Коды ответов

| Код | Когда возвращается |
|-----|--------------------|
| 200 | запрос выполнен |
| 400 | параметр имеет неверный формат (не число, меньше 1) |
| 404 | элемент с указанным id не найден |
