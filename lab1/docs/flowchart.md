# Flowchart: расчёт итоговой стоимости заказа

```mermaid
flowchart TD
    A([Начало]) --> B[Посчитать сумму блюд в корзине]
    B --> C{Есть промокод?}
    C -- Да --> D[Применить скидку к сумме]
    C -- Нет --> E[Скидка не применяется]
    D --> F{Сумма больше 30 руб?}
    E --> F
    F -- Да --> G[Доставка бесплатная]
    F -- Нет --> H[Добавить стоимость доставки 15 руб]
    G --> I[Показать итоговую сумму]
    H --> I
    I --> J([Конец])
```
